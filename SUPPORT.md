# Support

## Where to get help

For normal support, feature requests, and bug reports, please use the
[GitHub issue tracker](https://github.com/intelliThings-official/home-assistant-intellithings/issues).

- **Bugs** — report using the "Bug report" template if one is available, or
  open a new issue describing the problem, the steps to reproduce it, and
  relevant logs.
- **Feature requests** — open a new issue with a clear description of what you
  would like to see added and why.

**Do not use GitHub Issues to report security vulnerabilities.** Security
issues must be reported privately. See [`SECURITY.md`](SECURITY.md) for
instructions.

## Supported versions

- **Integration version:** The latest published GitHub release is supported.
  You may be asked to update to the current release before receiving support.
- **Home Assistant version:** This integration requires Home Assistant
  **2024.11.0** or later.

## About this integration

This is a **custom integration** maintained by **IntelliThings**.

It is **not** maintained or supported by:

- The Home Assistant project
- HACS (Home Assistant Community Store)
- The Open Home Foundation

Please do not contact those projects for support with this integration.

## Before opening a request

- Ensure you are running the [latest release](https://github.com/intelliThings-official/home-assistant-intellithings/releases)
  of the integration.
- Check existing [open and closed issues](https://github.com/intelliThings-official/home-assistant-intellithings/issues)
  to see if your question or problem has already been addressed.
- If the issue may be related to a security vulnerability, follow the process
  in [`SECURITY.md`](SECURITY.md) instead.
